## Overview

**XtrakT** is an intelligent OCR-first text extraction tool designed for high-accuracy document processing. It uses a sophisticated **4-stage hybrid pipeline** that combines traditional OCR engines with conditional LLM invocation and agentic validation to achieve maximum accuracy while minimizing costs.
